# 使用说明

### 1. 安装JDK 21、Maven和Git

```
winget install --id Microsoft.OpenJDK.21 -e
winget install --id Apache.Maven -e
winget install --id Git.Git -e
```

安装完成后，关闭PowerShell，再重新打开。

### 2. 检查安装

```
java -version
mvn -version
git --version
```

确认Java版本是21。

### 3. 下载项目

```
git clone https://github.com/libai1232/lead_agent.git
cd lead_agent
```

### 4. 设置API Key，中转站URL和模型名称（本项目使用的是micu）

```
$env:OPENAI_API_KEY="替换成自己的API Key"
$env:OPENAI_BASE_URL="https://www.micuapi.ai/v1"
$env:OPENAI_MODEL="gpt-5.6-sol"
```

### 5. 启动项目

```
cd lead_agent
mvn spring-boot:run
```

看到下面的日志表示启动成功：

```
Started LeadAgentApplication
Tomcat started on port 8080
```

保持这个PowerShell窗口运行。

### 6. 开始对话

浏览器打开：

```
http://localhost:8080/
```

输入：

```
customerId：customer-1
message：我想了解一下你们的产品
```

点击“发送”即可。
